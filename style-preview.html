Integrating Augmented Reality into Welding Instruction

A four-unit course preparing secondary CTE welding instructors to evaluate AR tools, interpret simulator feedback, and plan the move from simulated practice to live welding.

What this page is

A style preview, not a course page. Every element below is a component the real site will use. Nothing here is final content — the headings, unit titles, and copy are stand-ins so you can judge the system, not the words.

Navigation

Hover a menu item and the underline sweeps in from the left. Now press Tab and do it with the keyboard — the same animation fires on focus, which the reference template does not do. The Units menu opens on hover, on click, and on Enter, and closes with Escape.

The current page keeps a persistent underline and carries aria-current="page", so a screen reader announces it as the current page rather than relying on the visual cue alone.

Type scale

Poppins for headings and navigation, Manrope for body text. Headings scale fluidly with the viewport, so nothing is cramped on a phone or oversized on a wide monitor.

This is a heading level three

This is body copy at the size instructors will actually read. The measure is capped at 68 characters, which keeps lines short enough to track comfortably across a paragraph. Long instructional text is the main thing this site does, so the body face was chosen for sustained reading rather than for display impact.

Motion

All animation respects prefers-reduced-motion. If a viewer has asked their operating system to reduce motion, transitions and hover lifts stop and the interface still works exactly the same. On macOS that setting is System Settings → Accessibility → Display → Reduce motion.
